# Quickstart: Login Redesign

## Setup

1. Make sure you are on the `002-redesign-login` branch.
2. Install dependencies (if not already installed): `npm install`
3. Run the application: `npm run dev`

## Viewing the New Login Page

1. The app will usually open at `http://localhost:5173`.
2. If you are already logged in, you must log out first to see the Login page.
3. Observe the new UI built with the Konsta UI-based design system.
4. Try toggling the password visibility.
5. Check the "Ghi nhớ đăng nhập" checkbox.
6. Try logging in with valid and invalid credentials to see the respective states (loading, error toast).
